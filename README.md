# Sistema de Pagamento de Mensalidade - Jogos

Sistema completo para pagamento de mensalidade de jogos com múltiplas opções de pagamento.

## Como Pagar a Mensalidade

### 🌐 Interface Web (Recomendado)
1. Abra o arquivo `web_payment.html` no seu navegador
2. Escolha o método de pagamento:
   - 💳 **Cartão de Crédito/Débito** - Pagamento instantâneo
   - 📱 **PIX** - Pagamento instantâneo via QR Code
   - 📄 **Boleto Bancário** - Vencimento em 3 dias
   - 💰 **PayPal** - Redirecionamento seguro

### 💻 Interface de Linha de Comando
```bash
python3 payment_system.py
```

## Métodos de Pagamento Disponíveis

### 1. Cartão de Crédito/Débito
- Processamento instantâneo
- Todas as bandeiras aceitas
- Pagamento seguro com criptografia

### 2. PIX
- Pagamento instantâneo
- QR Code ou código para copiar e colar
- Válido por 30 minutos

### 3. Boleto Bancário
- Vencimento em 3 dias úteis
- Pagamento em bancos, lotéricas ou internet banking
- Código de barras incluso

### 4. PayPal
- Redirecionamento seguro
- Aceita cartões internacionais
- Proteção ao comprador

## Arquivos do Sistema

- `web_payment.html` - Interface web moderna e responsiva
- `payment_system.py` - Sistema backend em Python
- `payment_*.json` - Comprovantes de pagamento salvos

## Como Usar

1. **Via Web**: Abra `web_payment.html` no navegador
2. **Via Terminal**: Execute `python3 payment_system.py`
3. Escolha seu método de pagamento preferido
4. Preencha os dados solicitados
5. Confirme o pagamento

## Segurança

- 🔒 Dados criptografados
- 🛡️ Validação de cartões
- 📧 Confirmação por email
